_EPROCESS

KERNEL PROCESS OBJECT

The EPROCESS structure represents a Windows process inside the kernel. It contains important process metadata and references to other process-related structures.

What to look for
PID: 4820 PPID: 1096 Image: powershell.exe Threads: 7 Handles: 312
Forensic relevance

Analysts can use process structures to establish process identity, parent-child relationships and investigate suspicious execution.
